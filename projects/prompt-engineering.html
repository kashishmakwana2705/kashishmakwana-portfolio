🤖 Prompt Engineering

Prompt Engineering

Designing clear and effective AI prompts for content creation, research, brainstorming and creative problem solving.

📌 Project Overview

This project demonstrates my ability to write structured, goal-oriented prompts that help AI generate accurate, creative and high-quality responses.

I focus on providing clear instructions, defining the audience, choosing the right tone and refining prompts to achieve better outputs.

🎯 Objective

Create reusable prompt templates that improve productivity, enhance creativity and produce consistent results across different writing and design tasks.

🧠 Prompt Structure

  • Define AI's role clearly.
  • Provide detailed context.
  • Explain the specific task.
  • Identify the target audience.
  • Specify tone and writing style.
  • Review and refine the generated output.

✨ Example Prompt

Role

You are an experienced UX Writer.

Task

Create five friendly onboarding messages for a mobile banking application.

Requirements
  • Simple language
  • Professional but welcoming tone
  • Maximum 20 words each
  • Encourage users to continue onboarding

📊 Prompt Improvement

❌ Basic Prompt

Write a social media caption.

✅ Improved Prompt

Act as a social media strategist. Write an Instagram caption for a sustainable clothing brand targeting Gen Z. Use a friendly tone, include one call-to-action, three emojis and five relevant hashtags.

Through this project, I improved my ability to communicate effectively with AI tools while maintaining creativity, accuracy and user-focused thinking.
